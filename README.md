# PassGuard

Check, create and protect passwords. Runs fully in the browser (HTML, CSS, JavaScript). No backend, nothing stored.

Pages: Check password, Create password, Make hash, Verify hash (with ready-made samples), Demo Lab, Learn.
Dark mode by default with a light/dark toggle.

Run locally: `python -m http.server 8000` then open http://localhost:8000

Files: `index.html` (pages), `style.css` (themes), `engine.js` (analysis, generator, hashing), `app.js` (interface).
